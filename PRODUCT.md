# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + Vite + TypeScript, Tailwind CSS + shadcn/ui, Supabase (PostgreSQL + Auth + Storage), Dexie.js (IndexedDB), Recharts

## Users

1. **Elderly Patient**: Primary user with cognitive engagement needs. Requires extremely simple, accessible interface with one screen → one instruction → one main action. Needs multilingual support (English, Assamese).

2. **Family Caregiver**: Manages patient care remotely. Needs dashboard to monitor activities, manage reminders, and upload memory book entries. Desktop-optimized interface.

## Product Purpose

Offline-first, multilingual cognitive engagement and memory-assistance web application for elderly dementia patients in North Eastern Region of India. This is a SUPPORT application, NOT a medical diagnostic system.

## Positioning

Accessible, offline-capable cognitive support tool specifically designed for the North Eastern Region of India with local language support (Assamese), designed for low-connectivity environments and elderly users who need maximum simplicity.

## Operating Context

- Patients use tablets or smartphones, possibly with limited internet connectivity
- Caregivers use desktop computers to monitor and manage care
- Offline-first operation with sync when connectivity returns
- Voice instructions with fallback to text when Assamese voice unavailable
- No competitive elements, no ads, no diagnostic claims

## Capabilities and Constraints

**MVP Features:**
1. Language Selection (English, Assamese)
2. Patient Home with friendly greeting and navigation
3. Memory Game (object recall with accuracy, response time, hints)
4. Pattern/Attention Game (visual sequence completion)
5. Adaptive Difficulty (rule-based, transparent, non-diagnostic)
6. Reminders (medicine, hydration, daily activity with statuses)
7. Personalized Memory Book (family photos, names, relationships)
8. Caregiver Dashboard (authentication, analytics, management)
9. Offline-first operation with sync queue

**Constraints:**
- No medical diagnosis or severity measurement
- No medication prescription
- No facial recognition
- No emergency monitoring
- No hospital/wearable integration
- No video calling
- Maximum 2 games for MVP
- No complicated ML
- No native mobile apps

## Brand Commitments

- Warm, calm, credible healthcare/support product appearance
- No generic AI-generated SaaS template aesthetic
- Consistent design tokens throughout
- shadcn/ui components tailored to product needs
- High accessibility standards

## Evidence on Hand

- Project requirements document provided
- No existing codebase or assets
- Blank slate - greenfield project

## Product Principles

1. One screen → one instruction → one main action
2. Extremely simple patient interface with accessibility-first design
3. Offline-first operation with seamless sync
4. No medical claims or diagnostic functionality
5. Consistent, calm, professional healthcare aesthetic

## Accessibility & Inclusion

- Very large readable text
- Large touch targets
- High contrast
- Very few choices per screen
- Simple wording
- Calm feedback
- Minimal animations
- Clear icon + text labels
- Voice/replay instruction button
- No competitive leaderboards
- Multilingual support (English, Assamese)
